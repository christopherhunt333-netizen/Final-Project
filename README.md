# Wildspace — Final Project

Wildspace is a wilderness survival game. This is an unfinished game. 
Current Checkpoint: 1

---

## Objective

The current game objective is to collect 10 of each resource.

--

## Controls

| Action | Key |
|---|---|
| Forward | E / Up Arrow |
| Left | A / Left Arrow |
| Backwards | S / Down Arrow |
| Right | D / Right Arrow |
| Interact | E |
| Jump | Spacebar |
| Sprint | Left Shift |

## Folder Structure

| Folder | Purpose |
|---|---|
| Animations | Unity animations |

| Prefabs | Prefabs |
| Scenes | Unity scenes |
| Scripts | Gameplay scripts |
| Setting | Gameplay Settings |
